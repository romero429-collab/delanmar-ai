# Delanmar AI

Delanmar AI is an independent, human-led AI workforce and business automation project. It begins as a practical operating environment for Delanmar and is designed to become a reusable framework for small businesses.

## Initial workforce

The blueprint defines 24 specialized agents: 8 Communication agents, 14 Internal Operations agents, an Executive Personal Assistant, and a Project Manager. The Business Operations Director is a coordinating role, not an additional specialist agent. The human owner retains final authority.

## Pilot

The Delanmar OpenWorks Pilot will test selected customer intake, service preparation, scheduling, administration, and follow-up workflows in phases. It will establish baseline measures, apply human approval controls, and report only verified outcomes.

## Principles

- Human-led, AI-assisted operations.
- Specialized roles with explicit permissions and escalation paths.
- Shared business context with access controls and audit history.
- Human approval for consequential financial, legal, HR, and customer commitments.
- Measured results, not assumed productivity claims.
- Standalone operation first, with documented interfaces for future Kiyoshi interoperability.

This repository contains planning documents and implementation work. Features must not be described as implemented or validated until tested.
